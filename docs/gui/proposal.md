# GUI 操作面板 · 提案

## 背景

本工具当前只有两种入口：命令行子命令（`npm run patch` 等）与**控制台交互菜单**（`scripts/cli.js`，打包产物双击即此模式）。控制台菜单的每一步都要「看提示 → 敲数字 → 回车」，且必须开着黑窗口；对只想点两下完成汉化/还原的使用者不方便。

参考实现 `GithubDesktopZhTool.exe`（robotze/GithubDesktopZhTool，C# / WPF）提供了桌面窗口形态：工具栏按钮直接触发操作，下方表格展示字典，底部状态栏显示识别到的安装路径。本提案为**本仓库**新增同一形态的图形入口。

## 目标

- 双击 GUI 产物即出现桌面窗口，**不出现控制台**；汉化 / 还原 / 指定安装位置 / 检查更新由按钮直接触发。
- 窗口内可见当前状态：识别到的安装位置、应用版本、字典版本与条目数、是否已汉化、备份情况。
- 窗口内可见字典内容（**只读**表格：英文 / 中文 / 类型），用于核对译文，不做编辑。
- 现有 CLI 与 SEA 单文件产物**行为完全不变**，两套形态并存、互不干扰。

## 范围

- **做**：
  - 新增 `gui/`（Electron 应用：主进程 + 预加载桥 + 界面），复用 `scripts/` 全部业务逻辑（不重写替换、备份、还原、字典同步）。
  - 工具栏四个操作：**汉化**、**还原**、**选择安装位置**、**检查更新**，外加**刷新**（重读状态）。
  - 只读字典表格 + 搜索过滤（1862 条需可检索）。
  - 底部：安装根路径、进度指示；状态栏：识别结果 / 未识别提示。
  - `npm run gui`（开发态运行）与 `npm run dist`（electron-builder 产出 NSIS 安装包 / 便携版）。
  - `scripts/common.js` 的 `dataRoot()` 增加 Electron 运行形态判据（否则 GUI 打包产物会把备份与配置写进 asar 内部）。
  - 文档同步：`AGENTS.md`（架构 / 运行形态 / 常用命令）、`README.md`（使用方式增 GUI）、`docs/打包与分发.md`（GUI 构建）。
- **不做**：
  - **不做字典编辑**（添加 / 删除 / 保存 / 重载行）——字典是核心资产且有严格校验规则（整模板键 / 作用域键 / `buildEntries` 校验），GUI 内编辑不在本次范围。
  - **不做「提交提示词」标签页**——那是参考工具对应 `Temp/UserPrompt.txt` 的功能，本仓库的提交规范 SSOT 在 `.claude/skills/commit-create/`，GUI 内无对应物。
  - **不做平台下拉**（参考工具底部 Windows / Mac / Linux）——本仓库字典按**版本**组织、不含平台维度。
  - **不改动** `scripts/cli.js` 控制台菜单与 SEA 单文件产物；**不删除**任何现有入口。
  - **不做 CI 集成**（Electron 打包 job）与自动更新——待 GUI 本地稳定后另行迭代。
  - **不做** macOS / Linux 的 GUI 实测（本机为 Windows；打包脚本按当前平台工作，跨平台验证需在对应平台进行）。

## 验收标准

1. `npm run gui` → 出现标题为「GitHub Desktop - 汉化工具」的窗口，状态栏显示识别到的 `…\AppData\Local\GitHubDesktop`（与截图一致）。
2. 点「汉化」→ 弹确认 → 确认后窗口内显示命中处数，且安装目录 `app-<版本>/resources/app/renderer.js` 的产物与 `npm run patch` 的结果**逐字节一致**（同一字典、同一替换逻辑）。
3. 点「还原」→ 产物回到官方原版（或按字典逆向还原），与 `npm run restore` 结果一致。
4. 点「选择」→ 系统目录选择框 → 选中后状态栏与路径栏立即更新，并写入 `config.json`（与 CLI 的「指定安装位置」共用同一份配置）。
5. 字典表格显示 1862 条（3.6.6），列含英文 / 中文 / 类型；搜索框输入关键字可过滤。
6. `npm run dist` → 产出 NSIS 安装包；安装后从快捷方式启动 → **不出现控制台**，窗口正常打开，汉化可用，且备份写在安装目录的 `tmp/backup/`。
7. `npm test` 全绿；`npm run verify` 不受影响；`npm run build`（SEA 产物）产出的单文件 exe 行为与改动前一致。
