# translation-maintain — 翻译维护技能

本仓库（`.claude/skills/` 下）的项目技能，给 Claude Code 用于**汉化字典的日常维护**：把「更新翻译 / 补充翻译 / 纠正翻译问题」三类任务的流程、判定标准与取证工具固化下来，避免每次靠临场发挥（尤其是"译文把功能改坏"这类只能靠产物取证才能发现的坑）。

## 文件

- `SKILL.md` — 技能入口：三类任务的流程与铁律、字典匹配机制（三类键形态）、通用收尾（打包 → 验证 → 落地复查 → 提交）、可迁移性说明
- `references/版本升级.md` — 官方版本更新后重建汉化包的完整步骤（备份核验 → 派生字典 → 全量干跑找失效条目 → 重建整模板键 → 补译新增文案）
- `references/收录判定.md` — 「这条英文能不能译」的四步检查与已实证的不可译清单（含事故案例）
- `references/probe.cjs` — 探针模板，拷到 `tmp/` 改候选后执行；`dry` 模式在官方原文上预演命中，`land` 模式在汉化产物上复查残留

## 用法

在本仓库目录下提出任务即可自动触发（也兼容不带技能名的自然语言）：

- 「GitHub Desktop 升级到新版本了，更新一下汉化包」
- 「还是有没有汉化的，看截图」
- 「进度条不动了 / 计数不对，是不是翻译搞坏的」

技能正文是给 agent 的执行指令；面向人的项目说明见仓库根目录 `README.md`，仓库级约定见 `AGENTS.md` 的「翻译维护（字典迭代）」一节。
