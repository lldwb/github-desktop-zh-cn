# dictionaries/ — 语言字典（核心资产）

本目录是仓库的核心资产：**「原文 → 中文」翻译字典**，按 GitHub Desktop 版本目录组织。

## 目录约定

```
dictionaries/
├── 3.5.12/          # 按 GitHub Desktop 版本号分目录
│   └── zh-CN.json   # 该版本的字典
└── README.md
```

- **版本强对应**：字典必须与 GitHub Desktop 版本一一对应（错配可能导致应用无法启动）。
- **来源**：`main.js`（主进程）与 `renderer.js`（渲染进程）中硬编码的界面文本（含界面元素、读屏文本、命令行文本、报错文本；不含用户不可见的日志文本）。
- **自定义**：用户可按需在字典中覆盖 / 增补条目（字典为「原文 → 中文」映射，替换按精确串匹配优先、正则兜底）。

## 字典格式（规划）

条目格式与替换规则（精确匹配 / 正则 / 占位符处理）在补丁脚本实现时定稿，随 `scripts/` 工具链一并落地。
